SQL 로그 매핑 & Pretty 에디터

MyBatis 로그(==> Preparing / ==> Parameters)를 붙여넣으면 파라미터를 자동으로 바인딩하고, 순수 SQL만 붙여넣으면 바로 Pretty Print 합니다. 서버·외부 라이브러리 없이 이 파일 하나로 동작합니다.

1. 입력

입력에 ==> Preparing 패턴이 있으면 자동으로 "로그 매핑 모드"로, 없으면 "SQL Pretty 모드"로 동작합니다.

2. 결과

왼쪽에 로그 또는 SQL을 붙여넣고 변환 버튼을 누르세요.
로컬에서만 동작하며 입력한 내용은 어디로도 전송되지 않습니다. (외부 네트워크 요청 없음)
